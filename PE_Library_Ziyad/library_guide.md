# Library Guide — Learner Support Desk (TC)

## What is in the library
- `blocks/` — the Facts block: the only facts a template may use.
- `rules/` — the five fixed safety rules, copied into every template.
- `templates/` — five approved templates (answer, sort, soften, apologize, mask).
- `library_index.md` — the list of templates, versions and status.
- `Test_Results_Report.pdf` — the three tests for each template.

## How to use a template
1. Open the template file from `templates/` and copy the TEMPLATE section.
2. Fill the variables. Paste the Facts block into [FACTS]. If a value is missing, the default applies.
3. If the learner's message has names, phone numbers or emails, run `TC-Mask-Details` first and use only the masked text.
4. Paste the filled template into the approved AI tool.
5. Do not remove or change the RULES section. They are fixed.

## How to check an output (Day 4 checklist)
Before anything is sent, a person confirms:
- Every fact is in the Facts block and the block is current.
- Numbers, dates and names match the source exactly.
- No promised date and no "I did this".
- No personal data is repeated (only codes such as User-1).
- Every question is answered and the wording reads naturally.

A person always reviews the reply before it is sent.
