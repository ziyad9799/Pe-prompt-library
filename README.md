## Training Program
This project was completed as part of the Prompt Engineering and Responsible AI Use training program at SDAIA 
Academy, under the supervision of Abdullah Khalid AlShahrani.
The project demonstrates the practical application of prompt engineering and responsible AI use — building a 
clean, approved prompt library through structured RACE prompts, reusable templates with variables and fixed 
output formats, safe handling of sensitive data, verification and responsible-use rules, and a documented three-test quality report.
